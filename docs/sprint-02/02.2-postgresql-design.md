# Sprint 02.2 — PostgreSQL persistence design

Status: `LOCAL DESIGN IMPLEMENTED`

PostgreSQL 16 is the authoritative persistence provider. The schema contains
17 tables grouped into identity, proposal/review, publication, coverage,
authorization, stable-ID sequencing, and append-only audit concerns.

Mandatory database invariants include stable unique public IDs, exactly one Alias
target, a single trusted active claim per normalized barcode, one active coverage
per `(business_id, business_product_ref)`, merge survivor checks, and immutable
released snapshot content. JSONB is limited to structured pack data, attributes,
provenance, evidence, snapshot payloads, and audit values.

No table contains authoritative business price, cost, stock, availability, sales,
supplier, batch, or shop configuration. Coverage location data is only an opaque,
non-authoritative projection of canonical Ntheemba location IDs/display snapshots.

Implementation: `service/src/ncpc_service/models.py` and the first Alembic revision.
