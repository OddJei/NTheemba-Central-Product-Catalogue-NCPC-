# Sprint 02.3 — persistence implementation and migration

Status: `LOCAL IMPLEMENTATION VERIFIED`

SQLAlchemy models, transaction/session boundaries, concurrency-safe namespace
sequences, Alembic migration, PostgreSQL immutability triggers, and an Apps Script
v2 legacy importer are implemented.

The importer preserves existing `PRD-*` and `VAR-*` identifiers and barcode text,
including leading zeroes. It rejects TradeFlow-owned operational fields before
writing. Existing legacy releases are treated as references; a new exact immutable
snapshot must be published prospectively after import.

Evidence: the migration applies to SQLite for local structural tests, renders a
complete PostgreSQL SQL plan, and importer tests cover ID/barcode preservation and
protected-field rejection. Applying against a real PostgreSQL 16 instance remains
a deployment/runtime gate.
