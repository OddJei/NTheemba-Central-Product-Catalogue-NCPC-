# Sprint 02.7 — immutable publication system

Status: `LOCAL IMPLEMENTATION VERIFIED`

Publication selects approved, active Products and Variants and serializes an exact,
identity-only payload. Each item and release receive SHA-256 content hashes. A
release stores Product/Variant versions plus immutable payload bytes represented as
canonical JSON.

Only verified active barcodes and approved aliases enter a publication. Publishing
new content supersedes the prior release without changing any prior entry. Both
SQLAlchemy guards and PostgreSQL triggers reject released-content update/delete.
Approved submissions/coverage become published/trusted only when the resolved VAR
appears in a release.
