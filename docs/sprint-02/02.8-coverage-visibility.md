# Sprint 02.8 — BusinessCoverage and Ntheemba trust rules

Status: `LOCAL IMPLEMENTATION VERIFIED`

Effective visibility is derived from NCPC trust ceiling and the business's exposure
preference. The business may reduce exposure but cannot raise it above the ceiling.

| Coverage condition | Effective maximum |
| --- | --- |
| No coverage / rejected / withdrawn | Hidden |
| Submitted / needs information / stale / remapped | Provisional within business |
| Linked and approved but not in current release | Provisional within business |
| Linked, approved, in current release | Trusted wider discovery |

An approved business can reduce trusted wider discovery to trusted within-business
or hidden. The Ntheemba-only batch lookup accepts up to 50 unique VAR IDs and
returns only opted-in, active, approved coverage in the current release. It returns
opaque business/product/shop references and location projection only; Ntheemba must
still call TradeFlow for current price and availability.
