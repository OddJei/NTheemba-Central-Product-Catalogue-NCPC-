# Sprint 02.5 — versioned authenticated API

Status: `LOCAL IMPLEMENTATION VERIFIED`

FastAPI exposes `/health` and authenticated `/v1` routes. Bearer tokens are stored
as SHA-256 digests, roles/scopes are explicit, business calls are tenant-bound,
request IDs are returned, errors use stable safe codes, bodies are size-limited,
and a fixed-window per-process safety rate limit is applied. Production must also
enforce distributed rate limits at the ingress layer.

`POST /v1/tradeflow` preserves Sprint 01's seven-method NCPC client port:
`searchCandidates`, `getVariant`, `verifyVariant`, `submitProduct`,
`getSubmissionStatus`, `submitCorrection`, and `getCorrectionStatus`.

This is an adapter-ready contract only. Sprint 02.9 must replace TradeFlow's local
fake/release client and prove deployed HTTP failure/fallback behavior.
