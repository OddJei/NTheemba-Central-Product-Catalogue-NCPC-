# Sprint 02.4 — NCPC application service layer

Status: `LOCAL IMPLEMENTATION VERIFIED`

The application layer implements published candidate search, variant reads and
verification, idempotent new-product submission, idempotent correction submission,
tenant-safe status reads, review decisions, identity creation/correction, merge,
publication, coverage preferences, and visibility derivation.

External retry idempotency is scoped to the authenticated client plus idempotency
key. Business principals cannot read another business's submission or coverage.
Canonical identity changes occur only after review; a correction never rewrites an
already released snapshot.
